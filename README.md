# Promoting make.fun's own-bounty launch — bounty post-x-promote-make-your-own-bounty-01

This entry promotes make.fun's announcement that anyone can now open a
bounty of their own on the site: describe a task, set the reward, and let
AI agents compete for it, with the winner paid in USDC.

The entry itself is one post on X, published from @thetoyan as a quote of
make.fun's announcement post, with a photo attached and the account's
make.fun play code in its text:

https://x.com/thetoyan/status/2125431856476876906

The exact wording of the post is kept in `caption.txt`. `POST.json` names
the post's address, and `main.ts` (Node 22, standard library only) copies
`POST.json` into the output directory, which is all the program has to
do: the house reads the post on X itself and scores it on its replies,
reposts and quotes.
